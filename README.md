# NGU Save Tracker

An unofficial web tool for [NGU Idle](https://store.steampowered.com/app/1147690/NGU_IDLE/) players. Import your save
files to chart your progress, try gear swaps, and work out what to spend on next. Not affiliated with the game's
developers.

## Features

- **Progress:** charts and a day-by-day table across all your saves, with run and challenge bands.
- **Rates and targets:** gains per day, time for each NGU to reach a target level, and a milestone timeline.
- **Gear what-if:** swap items and see the effect on your stats, or find the best gear for a goal.
- **Calculators:** EXP spending and energy/magic balance, best augment pair, fruit timing, gold digger levels and upgrades, hackday and wish planners, rebirth length for beards and MacGuffins, and a cooking solver.
- **Checklists:** titan auto-kill readiness from your adventure stats, challenge clears left at each difficulty and what the next one needs, and which items each set still needs maxed.
- **Compare saves:** every field that changed between two saves, with item names.

## Privacy

Saves are parsed and stored only in your browser (IndexedDB), and are never uploaded. The app's code makes no network
requests, and the production build's Content-Security-Policy blocks every request except Cloudflare Web Analytics, which
is cookie-free and reports page loads (address, load time, browser), not save data. Saves contain your player name, which the app doesn't display, so treat a
downloaded backup like a save file.

## Accuracy

Formulas are written for game build 1260 and may be off on other builds. Results haven't all been compared with the
game's own screens. Known limits are stated next to each tool.

## Development

    npm install
    npm run dev      # local development
    npm test
    npm run build    # static site in dist/, deployable to any static host

- `src/save/`: NRBF parser, save decoding, metrics, run grouping, save diff
- `src/stats/`: stat formulas, gear what-if, and EXP, augment and fruit calculators
- `src/store/`: IndexedDB storage, import, backup
- `src/charts/`, `src/views/`: UI
- `src/data/itemNames.ts`, `src/data/itemSets.ts`, `src/data/wishes.ts`: item names, set members and wish limits, generated by the scripts in `tools/`

Metrics are re-derived from stored originals when `METRICS_VERSION` in `src/save/metrics.ts` is bumped.

The tests use a synthetic save fixture. Further suites compare results with real saves and values from a private
reference model, and they skip themselves when that data isn't present, as in a fresh clone or CI. To run the real-save
suite against your own saves, point `NGU_SAVES_DIR` at your save folder. No game files, saves or description text are
in this repo.

## Deploying

`npm run build` writes a static site to `dist/`. Asset paths are relative and navigation uses the URL hash, so it works
from any static host and path without server rewrites. The build also writes `dist/_headers` with the security headers
(the same Content-Security-Policy as the page's `<meta>` tag, plus `frame-ancestors 'none'`, which a `<meta>` tag can't
set), and long-lived caching for the hashed files in `assets/`.

The only outside address the policy allows is Cloudflare Web Analytics (`static.cloudflareinsights.com` for its script,
`cloudflareinsights.com` for its reports). Allowing anything else would break the promise that saves stay in the browser.

It's deployed as a Cloudflare Worker with static assets at `ngutracker.worksonmybench.dev` (`wrangler.jsonc`). The
address is permanent: saves are stored per address in the browser, so moving it would leave players' saves behind.
`npx wrangler dev` serves `dist/` with the headers locally.

CI deploys pushes to `main` once the repository variable `DEPLOY` is `true`, using the repository secrets
`CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`. Until then it only tests and builds.
